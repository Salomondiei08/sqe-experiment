02 · METHOD

Query-side intervention.
Memory stays fixed.

SQE changes the retrieval query, not the memory-writing policy or underlying index. The latest paper studies a pre-decoding confidence probe; the released experiment reports the top-1-score gate.

01

Retrieve

Run dense retrieval over the unchanged trace store.

02

Gate

Estimate whether the first result is enough.

03

Expand

Generate trace probes and paraphrases only when needed.

04

Fuse

Retrieve every variant and combine ranked lists with RRF.

↗
Why this matters

Expansion is useful when query language and stored execution traces use different registers. Indiscriminate expansion adds calls, latency, and opportunities to hurt precision.
